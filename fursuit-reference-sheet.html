Preparing a fursona reference sheet for a commission

Ask the maker what views and file formats they want. Use a neutral pose for each view so you can trace markings from one side of the body to the other. A shaded portrait is useful for mood, while flat-colour views make it easier to see where one colour ends and another begins.

Add notes where drawings leave a choice open

  • Label character left and right, especially if one ear or paw is different.
  • Show required markings that wrap around the tail, muzzle or inside of an arm.
  • Separate the features you need to keep from details the maker can adapt to materials and methods.
  • Confirm permission to share the artwork and to use the design for the commission where someone else drew it or owns the character.

Check the mock-up against the written scope

Ask how swatches will be reviewed and how the maker will handle a colour that is unavailable. Compare a draft against the required markings one change at a time. Send revisions as a single versioned file so both of you can tell which version you approved.

Example. If a reference shows a thin line down the character's right cheek, mark which side matters and ask what minimum width will read clearly in the maker's chosen materials. Agree on the compromise before construction.
